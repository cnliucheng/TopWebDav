WebDAV 端点

这里是 WebDAV 服务地址，供客户端挂载和同步使用，不是文件浏览页面。

This is the WebDAV endpoint for clients — not a file browser.

挂载方式 / Mounting

  • rclone：类型 webdav，URL 填 <本站地址>/dav，账号密码与网页登录相同
  • macOS Finder：菜单「前往 → 连接服务器」（⌘K），输入 http://地址:端口/dav，连接后选择「注册的身份」登录
  • Windows 资源管理器：此电脑 → 右键 → 「映射网络驱动器」或「添加网络位置」，地址填 http://地址:端口/dav
  • Cyberduck / RaiDrive 等：协议选 WebDAV，服务器地址同上

其他入口 / Elsewhere

  • 网页文件管理：返回首页
  • 直接访问文件：浏览器打开 /dav/路径/文件名 可直接查看或下载单个文件

账号密码与网页登录相同；网页端修改密码后，已挂载的客户端需更新密码。
